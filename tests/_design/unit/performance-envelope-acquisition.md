# Test Design — Enclosed certification workload acquisition

## Purpose and authority

Exercise the actual governed controller commands and validators through the native
whole-process envelope, without copying workload construction or promoting a new
admission rule. The current manifest, fixture inventory, resource limits and
baseline remain controlling authority. This adapter is diagnostic and unqualified.

## Scope

All 54 measurement coordinates: 50 latency (including two paired CLI coordinates
and two informational host-overhead coordinates), three peak-memory and one
artifact-size coordinate. The five functional resource groups remain separate
required checks, not claimed by acquiring measurements. Latency retains 512
warmups, 64 samples, all rejected attempts, fixed predeclared batches and existing
CLI allocation. Memory retains the existing one-measurement child protocol. Size
is a checked file observation, not a fabricated process interval.

## Categories of tests

-   Positive: drive every actual controller command builder and result validator
    with protocol fixtures; check complete commands, sample counts, paired controls,
    rejected observations, memory worker binding and exact artifact sizes.
-   Negative: unknown coordinate, missing or changed input, dirty/wrong source,
    altered manifest, invalid batch, non-native environment, failed envelope,
    malformed/duplicate/non-finite JSON, invalid controller results, replay and
    post-acquisition source drift must fail closed with no retry.
-   Interaction: explicit per-call executor injection leaves normal certification
    unchanged and continues to record raw measurement-process events. Exceptions
    preserve immutable raw logs and failed terminal records, not passing samples.
-   Native integration: a separately pinned, single-use diagnostic may exercise
    real product binaries only after clean source and build provenance verification.
    Synthetic fixtures are not product measurements or reference qualification.

## Completion criteria

Focused and direct-dependent tests pass on native Windows and WSL. Every result
denies certification eligibility. Existing live conditioning is unchanged; no
baseline regeneration, cap change, sample omission, normalization or reference
selection is authorized. Fresh independent reference nine, source-distinct holdout
nine, all conditioning challenges and independent trust remain required.

## Native memory result domain

The production RSS parser must accept exact positive JSON integers only; Python
booleans must not become one-byte passing samples. Exercise the actual direct
controller parser and envelope acquisition adapter with booleans, zero, negative,
floating-point, string and null values. Preserve raw output, failed receipts and
the one-attempt boundary. Valid integers, including values beyond exact float
precision, must survive unchanged. These synthetic protocol tests establish parser
integrity only, never memory residency, conditioning or empirical qualification.
